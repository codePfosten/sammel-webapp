# Kleine Aufgabenfolge — nur LEGO

Der alte M0/M1/M2-Plan wurde am 24.10.2026 als aktiver Entwicklungsplan abgelöst. Den bestehenden Code nicht neu aufbauen.

| Schritt | Auftrag | Fertig, wenn |
|---|---|---|
| L0 | Bestehende Website ausprobieren / ggf. gezielte UI-Fehler beheben | Manuelle LEGO-Erfassung bleibt funktional und verständlich |
| L1 | Optionen für bildgestützte Minifiguren-Erkennung prüfen | Datenquellen, mögliche Genauigkeit, Kosten und Fotodatenschutz realistisch eingeordnet; noch keine Anbieterfestlegung |
| L2 | Bestätigungspflichtige Erkennung integrieren | Foto erzeugt Kandidaten; bestätigter Treffer befüllt vorhandenes Formular; Korrektur/manuelle Eingabe bleiben möglich |
| L3 | Aktuelle Preisquelle prüfen und integrieren | nachvollziehbare Schätzung mit Quelle/Stand, Angebot vs. Verkauf klar getrennt; manuell überschreibbar |
| L4 | Nutzerbewertung | Erst danach über weitere Schritte entscheiden |

Nicht in diesen Tasks: universelle Sammel-App, weitere Sammlungen/Kategorien, Attributeditor, Such-/Sortierfunktionen, Statistiken, News, Cloud, Sync, Frameworkwechsel, PWA. Auch keine vermeintlich vorsorgliche Architektur dafür.

Hinweis: L1/L3 erfordern vor tatsächlicher Integration konkrete Quellen- und Kostenprüfung. Daten **werden weiterhin lokal gespeichert**; mögliche externe Erkennungs-/Preisabfragen sind davon zu unterscheiden.
